## Sobre Mim

Sou Desenvolvedor Full Stack especializado no ecossistema **.NET (C#)** e **Angular**, focado em entregar soluções que unem robustez no backend e usabilidade inteligente no frontend. Meu trabalho vai além da implementação de código: busco entender profundamente o problema, a regra de negócio e a estrutura de dados para criar sistemas eficientes e de alto impacto.

Tenho experiência prática no desenvolvimento e sustentação de aplicações web, refatoração de fluxos corporativos complexos, integração de sistemas e criação de interfaces aplicando heurísticas de Nielsen. Meu objetivo é sempre traduzir desafios de negócio em softwares escaláveis, seguros e desenhados para proporcionar a melhor experiência ao usuário final.
